# KinoPub

Онлайн **КиноПаб** (`ModuleConf`): API по умолчанию **`https://api.srvkp.com`** (в комментариях перечислены альтернативные базы для apk/TV). **`with_search.Add("kinopub")`**.

## Интерфейс

**`IModuleLoaded`**, **`IModuleOnline`**, **`IModuleOnlineSpider`**.

## Поведение

**`Invoke`** и **`Spider`** всегда возвращают **`new(conf)`**.

## Конфигурация

Секция в `init.conf`: **`KinoPub`** (`ModuleConf`).

По умолчанию: **`displayindex = 320`**, **`httpversion = 2`**, **`rhub_safety = false`**, **`filetype`** (**`hls`** / **`hls4`** / **`mp4`**), **`stream_access`**, заголовки «навигации» для запросов.

## Озвучки сериала (`filetype = hls`)

Список озвучек сезона собирается по дорожкам всех серий. Озвучка определяется ключом **`author.id ?? type.id`** + **`codec`** + **`lang`**; дорожка без автора и типа получает id **`6`** (английский оригинал) или **`0`** (по умолчанию). Неизвестный язык (пусто, `und`, `unk`) относится к единственному известному языку этой озвучки в сезоне, если в той же серии нет её дорожки с языком. Индекс дорожки (`a{index}.m3u8`) ищется в каждой серии отдельно, серии без выбранной озвучки не выводятся.

Если **`t`** не указан или озвучка не найдена, выбирается озвучка с наибольшим весом: число серий, умноженное на 4 для русской дорожки или на 2 для дорожки без языка, и ещё на 2 для `aac`.

Параметры **`lite/kinopub`**: **`s`** — сезон, **`t`** — id озвучки, **`codec`**, **`lang`** — необязательные уточнения. В названии озвучки язык указывается для нерусских дорожек, кроме английского оригинала. Если названия совпадают, его сохраняет озвучка с известным языком и наибольшим числом серий, остальным добавляется язык (`und`, если неизвестен), а при повторном совпадении — `#id`.
